Kaaka is a community help line run from one Android phone and one laptop. Callers need nothing but a phone that can call or text: Kaaka rejects the call so it costs them nothing, replies by SMS, alerts the nearest responder, and shows every caller on a live map.

**Built at [Devin Hacks Kochi](https://www.devinhacks.in/), 24 October 2026.**

## Downloads

| File | What it is | Install on |
|---|---|---|
| `Kaaka-Call-1.0.0.apk` | The Kaaka number: screens calls, replies by SMS, texts responders, reports to the control room | One Android 10+ phone with a SIM |
| `Kaaka-Sensors-1.0.0.apk` | Optional caller app: SOS, fall detection, safety timer, "I'm safe", GPS reports by SMS | Callers' own phones |
| `kaaka-server-1.0.0.tar.gz` | Control room server, landing page, docs and service files | A laptop or server with Python 3.12+ |
| `SHA256SUMS.txt` | Checksums for the files above | |

Both APKs are release-signed (certificate SHA-256 `8e6996ee…ac6e51`) and not debuggable.

## Upgrading from a pre-1.0 build

Earlier test builds were debug-signed. **Uninstall the old Kaaka Call and Kaaka Sensors first**; Android refuses to update an app whose signing key changed. Uninstalling clears the app's settings, so note the dashboard address and token before you do. From 1.0.0 on, new versions update in place.

## Quick start

```bash
tar -xzf kaaka-server-1.0.0.tar.gz && cd kaaka-server-1.0.0
python3 -m venv .venv && .venv/bin/pip install -r server/requirements.txt
export KAAKA_ADMIN_TOKEN="$(openssl rand -hex 24)"
.venv/bin/python server/server.py
```

Open `http://<ip>:8080/admin`, install Kaaka Call on the phone, and set its dashboard server and token. The full guide is served by the server itself at `http://<ip>:8080/docs/`: getting started, every SMS command, troubleshooting, and running in production with systemd or launchd.

## What's in 1.0.0

- **Kaaka number:** call screening including saved contacts, auto-reply in English, Malayalam or both, help by SMS (HELP, SOS, KAAKA, സഹായം), responder alerts, ACK / STATUS / RESOLVE commands, caller SAFE, escalation after 5 minutes, per-caller rate limiting, heartbeat to the control room.
- **Control room:** incidents grouped per caller on a live map with trails, nearest-responder dispatch with distance and ETA, history with search and CSV export, analytics, responder registry, macOS notifications, location-sharing links for callers without the app.
- **Kaaka Sensors:** SOS button, fall detection, safety timer, beacon every 15/30/60 s, "I'm safe", first report sent natively even when Android blocks the app from opening.
- **Production basics:** admin token, public `/api/health`, security headers, runs as a service (systemd and launchd files included), `KAAKA_DATA_DIR`, clean shutdown, pinned dependencies, 22 server tests and 19 Android tests in CI.
- **Website:** landing page at `/` and user docs at `/docs`.

## Known limits

- Kaaka cannot speak to callers: Android gives apps no call audio.
- Fall detection is an untuned heuristic.
- Distances and ETAs are straight-line estimates at 25 km/h.
- Location links need the control room on a public https address.

Kaaka works alongside 112, never instead of it. In immediate danger, call 112.
